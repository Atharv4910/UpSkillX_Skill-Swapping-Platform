# UpSkillX

UpSkillX is an AI-powered mentorship platform that connects learners with mentors based on their skills. It uses the Google Gemini API to generate skill assessments that reward users with credits. These credits can be used to book mentorship sessions, while features like follow requests, messaging, and session scheduling enhance the learning experience.


## Features

- 🔍 Skill-based mentor discovery
  - Find mentors whose expertise matches your skills and learning goals.

- 🤖 AI-generated skill assessments
  - Take personalized tests generated using the Gemini API.
  - Earn credits by successfully completing assessments.

- 💰 Credit-based mentorship system
  - Use earned credits to schedule mentorship sessions.
  - Credits are automatically deducted after a completed session.

- 👥 Mentor networking
  - Send and receive follow requests.
  - Build your professional learning network.

- 💬 Real-time messaging
  - Chat with mentors before and after connecting.

- 📅 Session scheduling
  - Schedule mentorship sessions based on mentor availability.

- 🔐 Secure authentication
  - User authentication and data management using Firebase.

## Tech Stack

- Java
- JavaFX
- Firebase Authentication
- Firebase Firestore
- Gemini API
